# Режим self — ревью силами Claude

Область — принесённое изменение. Если дифф не дан, возьми его сам:
`git diff` для рабочего дерева, `git diff HEAD~1..HEAD` для последнего коммита.

## На что смотреть, по приоритету

Порядок не декоративный: находка из верхнего пункта важнее любого количества
находок из нижнего.

1. **Корректность.** Логические ошибки, неучтённые ветки, race conditions,
   необработанные `None`/пустые коллекции, порядок операций при частичном сбое.
   Вопрос к каждой ветке: что будет, если сюда придут неожиданные данные?
2. **Безопасность.** Инъекции, необработанный пользовательский ввод, права
   доступа и владение объектом, секреты в коде и логах, небезопасная
   десериализация. Отдельно: изменение, ослабляющее существующую проверку.
3. **Надёжность на проде.** Внешние вызовы без таймаута, отсутствие ретраев там,
   где сбой ожидаем, неидемпотентные операции, поведение при рестарте сервиса.
4. **Производительность.** N+1 и запросы в цикле, отсутствующие индексы под новый
   фильтр, загрузка коллекции целиком ради одного элемента, блокирующий вызов в
   async-контексте.
5. **Границы и поддерживаемость.** Бизнес-логика, протёкшая во вью или шаблон;
   дублирование уже существующей в проекте функции; имена, которые врут;
   функция, которую невозможно протестировать без половины приложения.

Не пересказывай общие принципы (SOLID, DRY, KISS) — называй конкретное место и
конкретное последствие.

## Формат отчёта

Без эмодзи.

```markdown
## Вердикт

Что делает изменение: [1–2 предложения]

**APPROVE** / **APPROVE WITH COMMENTS** / **REQUEST CHANGES**

## Критичное (must fix)

| Проблема | Где | Чем опасна | Исправление |
|---|---|---|---|
| ... | `file.py:42` | ... | ... |

## Замечания

- **[WARNING/SUGGESTION]** описание
  - Сейчас: `фрагмент`
  - Предложение: `фрагмент`
  - Почему: [последствие, а не «так принято»]

## Удачные решения

- [конкретно, что сделано хорошо]
```

Раздел «Критичное» с пустым содержимым не выдумывай — пиши «критичных находок
нет».

## Тон

Объясняй **почему**, а не только «неправильно»: ревью, из которого нельзя
научиться, приходится повторять. Объяснения по-русски, идентификаторы,
термины и код — по-английски. Сначала критичное, потом остальное.
